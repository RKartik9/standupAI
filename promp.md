# StandupAI — Premium Light Mode UI Design Prompt

## Vision

Build a **premium, editorial-grade SaaS product** that feels like it was designed by a senior product designer at Linear, Notion, or Vercel — not generated by AI. Light mode only. No dark mode toggle needed.

The closest design references:

- **Linear** — tight spacing, monochrome base, razor-sharp type
- **Clerk** — premium white surfaces, confident typography
- **Raycast** — editorial feel, unexpected font pairing, intentional negative space
- **Loom** — clean SaaS homepage, real product screenshots, no fluff

---

## Typography (NON-NEGOTIABLE)

Use **Google Fonts**. Import via `<link>` in `layout.tsx`:

```
https://fonts.googleapis.com/css2?family=Instrument+Serif:ital@0;1&family=DM+Sans:opsz,wght@9..40,300;9..40,400;9..40,500&display=swap
```

- **Display / Hero headings**: `Instrument Serif` — elegant, editorial, premium. Use italic for emphasis words.
- **All UI copy**: `DM Sans` 300/400/500 only — never 600, never 700 outside serif headings
- **Monospace accents** (optional, for code/data): `font-family: monospace` system font

### Type Scale


## Color Palette (EXACT VALUES — DO NOT DEVIATE)

```css
:root {
  /* Surfaces */
  --bg: #fafaf8; /* warm off-white, never pure white */
  --surface: #ffffff; /* card/panel background */
  --surface-2: #f5f4f0; /* secondary surface, input bg */
  --surface-3: #eeece7; /* tertiary, dividers bg */

  /* Borders */
  --border: #e8e6e0; /* default border */
  --border-2: #d4d1c9; /* emphasis border */
  --border-3: #c0bdb4; /* strong border */

  /* Text */
  --text-primary: #1a1916; /* near-black, warm tint */
  --text-secondary: #6b6860; /* muted body */
  --text-tertiary: #9b9890; /* placeholder, hints */

  /* Accent — single accent, used sparingly */
  --accent: #1a1916; /* primary CTA = near-black (confident, not colorful) */
  --accent-hover: #2d2c28;

  /* Semantic (minimal use) */
  --green: #16a34a;
  --red: #dc2626;
  --amber: #d97706;
  --blue: #2563eb;

  /* Semantic surfaces */
  --green-surface: #f0fdf4;
  --red-surface: #fef2f2;

```

**Rules:**

- NO purple. NO indigo. NO gradient backgrounds. NO colored hero sections.
- The only gradient allowed: `background: linear-gradient(180deg, #FAFAF8 0%, #F5F4F0 100%)` — subtle, warm, maximum 2 stops.
- Primary CTA button = near-black background with white text. This is the premium choice.
- Never use blue as accent. Blue is only for links and informational states.

## Animation Guidelines

Use **Framer Motion** for:

```tsx
// Page/section entry
initial={{ opacity: 0, y: 16 }}
animate={{ opacity: 1, y: 0 }}
transition={{ duration: 0.4, ease: [0.16, 1, 0.3, 1] }

// Staggered children
variants={{
  hidden: { opacity: 0, y: 12 },
  visible: (i) => ({
    opacity: 1, y: 0,
    transition: { delay: i * 0.08, duration: 0.35, ease: [0.16, 1, 0.3, 1] }
  })
}}

// Hover on cards
whileHover={{ y: -2 }}
transition={{ duration: 0.15 }}
```

**Rules:**

- No spring bounce on UI elements (only on decorative/illustrative)
- No opacity flicker — always start opacity: 0, not 0.5
- No scale transforms on cards — only translateY(-2px) on hover
- Skeleton loaders: use `animate-pulse` from Tailwind, warm gray `bg-stone-100`

## What NOT to Do

```
✗ No purple, indigo, violet anywhere
✗ No gradient hero backgrounds
✗ No glowing text effects
✗ No glassmorphism (backdrop-filter: blur is OK only on nav)
✗ No rounded pill buttons on primary CTAs
✗ No emoji in UI (use SVG icons from lucide-react)
✗ No Inter or Roboto (wrong vibe entirely)
✗ No colored avatar backgrounds (use warm neutrals only)
✗ No box-shadow: 0 0 20px rgba(124,106,247,0.4) — ever
✗ No section with colored background except var(--surface-2) for subtle differentiation
✗ No "✨ AI-powered" badge with sparkle emoji
✗ No feature cards with colorful icon backgrounds
```
